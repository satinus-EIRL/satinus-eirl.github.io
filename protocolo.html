Línea de producto · preliminar

Protocolo Toroidal Distribuido

Coordinación y réplica por forma: eliges la geometría del cluster; el protocolo ordena, coloca y audita. Middleware para clusters pequeños/medios — no sustituye TCP/IP ni un CDN.

v1.0 TRL ~4 · prototipo operable Licencia propietaria · B2B
Consultar licenciamiento Centro de documentación

Promesa

Qué resuelve

En lugar de cajas negras de consenso o topologías accidentales, el Protocolo Toroidal declara invariantes medibles: mensajes por ronda, tolerancia a fallos y localidad de datos — con geometría (poliedros, toros, genus) como unidad de diseño.

Qué incluye (prototipo)

  • Selector de geometría (Tetra, Szilassi, toro, platónicos/arquimedianos)
  • Control plane Ring / Flood / Unicast con auditoría exacta
  • Shards put/get con colocación determinista + SQLite por nodo
  • Ledger consortium append-only (N ≤ 7)
  • Catálogo media (metadatos Ring; bytes fuera del Ring)
  • SDK Python + CLI + API HTTP(S)

Qué no es

  • Reemplazo de TCP/IP — vive sobre transporte
  • Kafka / bus masivo de eventos
  • Blockchain L1 pública
  • CDN o streaming de video
  • PaaS multi-tenant llave en mano (hoy: self-host + licencia)

Encaje

Casos de uso prioritarios

Edge N = 4–7 Réplica ordenada (Tetra / Szilassi) + ledger opcional
Geo / series Shards en toro: dato cerca de su vecindario topológico
Consortium Bitácora compartida de pocos nodos de confianza (N ≤ 7)
Índice media Catálogo «quién tiene qué chunk» — no el streamer
