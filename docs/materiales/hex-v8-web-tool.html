Herramienta · HEX V8

HEX: Encoder / Decoder

Codifica texto UTF-8 en un símbolo hexagonal ternario (trits negro / gris / blanco) y verifica la lectura desde una imagen PNG — todo en el navegador, sin servidor.

  • Encode: payload + nivel N → PNG con anillo visual, quiet zone y datos RS-M.
  • Decode: sube el PNG y recupera el texto; opcionalmente indica N.
  • Alcance: demostración y laboratorio — no sustituye el lector Android de campo (§8.4 del preprint).
