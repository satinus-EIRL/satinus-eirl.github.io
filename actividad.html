Operación

Cómo funciona el negocio

Satinus opera como laboratorio de I+D. Investiga, publica materiales de evaluación y licencia el uso industrial: toma problemas computacionales o estándares insuficientes y los convierte en soluciones propias. El valor está en PI, software y conocimiento aplicado — no en comercio físico masivo ni en consultoría genérica.

  1. Investigar — formatos, protocolos, IA y herramientas con evidencia.
  2. Publicar — especificación, informe, preprint, demos y campo.
  3. Licenciar — licencia / PoC / I+D a pedido bajo acuerdo escrito.

Mercado

A quién vendemos

Canal B2B. El primer círculo (2026) está en operaciones, planta, OT/TI y cadena de suministro: cuellos de botella de estándar o sistema (trazabilidad, lectura móvil o industrial, etiquetado, logística). También hay evaluación civil, investigación y colaboración técnica para que el estándar viva.

Entrega

Cómo distribuimos

Distribución digital: sitio web y centro de documentación para materiales públicos; GitHub / GitHub Pages para informes, preprint y releases; entrega contractual de licencias, builds o servicios mediante acuerdo escrito. No operamos tienda física ni logística de mercancía tangible como eje del giro.

Insumos

A quién compramos

No hay cadena manufacturera de materia prima. Adquirimos insumos de operación digital e I+D: equipamiento informático, software libre/open source, servicios cloud y de desarrollo (p. ej. GitHub), dominio, hosting y comunicaciones. Esos insumos sostienen la producción de software y documentación; no se revenden como mercancía al cliente final.
